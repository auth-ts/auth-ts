# auth-ts

Free forever JWT auth in TypeScript — callbacks to write into any database.
No adapters, no service, no company.

Apache-2.0. Community maintained.

- `@auth-ts/server` — the issuer. Zero framework dependencies, zero database dependencies.
- `@auth-ts/client` — browser token management.

Docs: [authts.dev](https://authts.dev) (coming soon).
