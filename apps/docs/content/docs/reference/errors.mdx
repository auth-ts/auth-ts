Every failed response has the same flat body:

```json
{ "name": "AuthError", "code": "rateLimited", "message": "…", "retryAfter": 30 }
```

The client throws it as an `AuthError`. Branch on `code`: codes never change,
while messages can be [translated](/docs/guides/emails#translating-messages).

Each row below is a code, with its HTTP status in the type column.
