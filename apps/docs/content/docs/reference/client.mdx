```ts title="lib/auth-client.ts"
import { createAuthClient } from "@auth-ts/core/client"

export const authClient = createAuthClient()
```

`@auth-ts/core/client` has no dependencies and none of the server code.
Creating the client makes no request and touches no storage, so it's safe during
server-side rendering. The access token lives only in memory.

## Methods

Browser methods, except `getToken`, `refresh`, `setLocale`, `clearToken` and
`decodeToken`, call the endpoint of the same name on the
[server](/docs/reference/server).

<auto-type-table path="client/core/create-auth-client.ts" name="AuthClient" />

Native account listing and switching operate over securely stored sessions.
The token exchange uses POST in both transports. See [Native apps](/docs/guides/native-apps).

## Errors

Server refusals are an `AuthError` with a stable `code`. Branch on the code;
the message is translatable and may change. Invalid native configuration,
unsupported provider navigation and superseded account changes raise a local
`Error` before an unsafe result can be used.

```ts
import { isAuthError } from "@auth-ts/core/client"

try {
  await authClient.sendSignInCode({ email })
} catch (error) {
  if (isAuthError(error) && error.code === "rateLimited") {
    showCountdown(error.retryAfter)
  }
}
```

A dropped connection throws `AuthNetworkError` instead. The full list of codes
is on [Errors](/docs/reference/errors).

With TanStack Query, register the type once and every `error` has `code`:

```ts
import type { AuthError } from "@auth-ts/core/client"

declare module "@tanstack/react-query" {
  interface Register {
    defaultError: AuthError
  }
}
```
