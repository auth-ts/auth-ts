```ts title="lib/auth.ts"
import { createAuth } from "@auth-ts/core"

export const auth = createAuth({
  database: authDatabase,
  email: { sendCode }
})
```

`createAuth` does no I/O and throws an `AuthConfigError` naming the bad option,
so a broken config fails at startup, not on the first sign-in. It returns the
[server API](/docs/reference/server).

## Durations

Durations are strings like `"30s"`, `"10m"`, `"1h"` or `"10d"`. Months aren't
supported, because their length varies.
